# Skill Catalog

Master index of all skills available in this hub. This tracks what EXISTS
here, not what's installed in any specific project.

Skills are organized on disk by **original source** — each source repo gets
its own folder under `skills/<source-owner>/`, so you can always tell where a
skill came from. Path column below is relative to the repo root.
